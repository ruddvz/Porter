Setup checklist
  1. Deploy this repo to Vercel (one-click button above).
  2. Copy every variable from .env.example into Vercel Environment Variables.
  3. Set NEXT_PUBLIC_APP_URL to your Vercel URL for auth and track links.
  4. Optional: add repository variable PORTER_LIVE_URL so this page shows an Open Dashboard button.
  5. Sign up, complete onboarding, and share your store link.
